# Prompt 09 - Run, Debug, and Fix Loop

I am running the project locally. Help me debug using evidence from build output and runtime logs.

Do not guess. Ask for or inspect:
- Maven build output
- Spring Boot startup logs
- Kafka connection logs
- Browser console errors
- Network tab request/response
- Angular compile output

For each failure:
- Identify the likely root cause
- Point to the exact file/class/config
- Provide the smallest safe fix
- Explain why the fix works
- Provide the command to verify it

Avoid broad rewrites. Use targeted changes.
